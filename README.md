# PAG34 · Genomics of Crop Ecosystem Services

Static GitHub Pages workshop site for Sunday, January 10, 2027, 4:00–6:10 PM PST, Pacific E, San Diego.

## Preview

Run `python -m http.server 8034` from this directory and open http://localhost:8034.

## Publish

Publish this code to the intended GitHub repository. In Settings → Pages, choose **GitHub Actions** as the build source. The included workflow deploys pushes to main. No build step or dependencies are required.

Repository: https://github.com/PGML-UGA/PAG34. This site was adapted from the PAG33 workshop archive.

## Content maintenance

Edit index.html for content, styles.css for appearance, and script.js for sharing/deadline behavior. Update workshop.ics and the Event JSON-LD when the schedule changes. Calendar times are stored in UTC (January 11, 00:00–02:10 UTC corresponds to January 10, 4:00–6:10 PM PST). The deadline is the organizer’s speaker-name submission deadline, not a separate registration deadline. No unconfirmed speakers are listed.

Workshop details come from Andrew Paterson’s invitation and correction to PAG34 (2027). Conference dates are confirmed at https://www.intlpag.org/PAG/. The redesigned site uses system fonts and local optimized images with no third-party runtime or font dependencies. Photo licenses and sources are documented in credits.html and assets/credits.json. UGA’s logo is used unmodified on a link to its institutional research resource. The DNA workshop mark is original artwork. The proposal form creates a mailto draft only; no data is stored or submitted by the site. Interactive research tabs support keyboard navigation, sections respect reduced-motion settings, and native FAQ disclosures work without JavaScript.

## Previous presenters

The Special thanks section credits the six presenters in the PAG33 January 12, 2026 program. Portrait provenance and original profile links are recorded in assets/presenters/sources.json and credits.html. Public professional portraits are not labeled as Creative Commons images.
